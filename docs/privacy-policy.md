# Privacy policy — Expense Tracker (V1)

**Last updated:** 6 September 2026

**Developer:** Dinesh  
**Android package:** `com.dineshkumar.expensetracker`  
**App:** Expense Tracker (offline V1)

This page is written in plain language so you can paste it onto GitHub Pages, Notion, or a public gist and give Google Play an HTTPS URL.

## Short version

V1 is **offline-only**. Your money data stays on **this device** as a local JSON file. There is no backend, no account server, and no login or password. We do not operate a cloud copy of your data.

## What the app stores on your device

When you start the app you type a **display name**. That name, plus the accounts, categories, transactions, budgets, and upcoming payments you add, is saved in a JSON file on the phone (`expense-tracker-v1.json` in the app’s private storage). A small local session flag is also stored on the device so the app can remember that you already started. It is not a password.

The app does **not** ask for an email or password in V1.

## What we do not collect

- No account is created on a server.
- No finance data is uploaded to a backend we run.
- This V1 build does not include an analytics, crash-reporting, or advertising SDK.

Google Play may still collect install and crash information under **Google’s** own policies. That is separate from this app.

## Export

**Export data** (in Settings) is something **you** start. It writes a copy of the same local JSON file and opens the system share sheet so you can save or send it. We do not upload that file. If you share it with another app or person, their privacy rules apply.

## Erase and uninstall

**Erase all local data** (in Settings) wipes the JSON file and the local session on this device. Uninstalling the app also removes that local data.

There is **no cloud copy** for us to delete. If you exported a file earlier, that copy is yours to delete.

## Notifications

The app can show **local reminders** for upcoming payments (for example, due dates you set). Those notifications are scheduled on the device. They are not sent through a push server we operate. You can refuse notification permission; the rest of the app still works.
